About BookNest

What is BookNest?

BookNest is a book search and reading-tracker web application. It allows users to search for books using the Open Library API and maintain a personal reading list.

Features

  • Search millions of books from the Open Library collection
  • View detailed information about books including covers, authors, and descriptions
  • Create and manage your personal reading shelf
  • Simple, accessible, and responsive design

Technology Stack

This project is built with vanilla web technologies:

  • Frontend: HTML5, CSS3, and vanilla JavaScript
  • Backend: Node.js with Express
  • Data Storage: JSON file-based storage
  • API: Open Library API

Open Library

Book data is provided by the Open Library, an open, editable library catalog building towards a web page for every book ever published.
