# BookNest Server

This folder will contain the Node.js + Express backend for BookNest.

## Planned Structure

- `server.js` - Main Express application
- `data/` - JSON file storage (gitignored)
- Additional route and utility files as needed

The server will:
- Serve the `/client` folder as static files
- Provide API endpoints for managing the reading shelf
- Handle data persistence in JSON format
